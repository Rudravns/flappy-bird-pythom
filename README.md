# Flappy Bird

A simple Flappy Bird-style game built with Python and Pygame.

## How to run

1. Install Pygame if needed:
   ```bash
   pip install pygame
   ```
2. Start the game:
   ```bash
   python main.py
   ```

## Controls

- Press Space or Up Arrow to flap
- Press the window close button to exit

## Features

- Classic falling-and-flapping gameplay
- Random pipe generation
- Score tracking and best score
- Start screen and game-over restart flow

## Project files

- `main.py` – game loop and rendering
- `bird.py` – bird physics and drawing
- `pipe.py` – pipe logic and collision checks
